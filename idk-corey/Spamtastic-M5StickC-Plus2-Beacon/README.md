# SPAMTASTIC! - Ultimate Beacon Master for M5StickC Plus2

## 🚀 Project Overview
The ultimate WiFi beacon spam tool with 50 categories and hundreds of creative beacon names. Built for M5StickC Plus2 using Bruce-style beacon spam functionality.

## ✨ Features
- **50 Beacon Categories** including:
  - Government agencies (CIA, NSA, DEA)
  - Horror themes (Hellraiser, Zombie Apocalypse)
  - Holidays & Seasons
  - Music quotes (Dead Kennedys, Crass)
  - Aliens, Sports, Astrology
  - Symbols, Emojis, International characters
  - And many more!

- **Easy Navigation**:
  - Button A (Left): Cycle through categories
  - Button B (Right): Start/Stop beacon spam
  - Power Button: Reset device

- **High Performance**: Fast beacon rotation (100ms intervals) for maximum WiFi spam effectiveness

## 🔧 Installation

### Option 1: M5Burner Package (Recommended)
1. Use the pre-built M5Burner package: `releases/v1.0-Final/M5Burner_Package/BeaconMaster-v1.0-FINAL.bin`
2. Flash directly using M5Burner tool

### Option 2: PlatformIO
1. Open project in PlatformIO
2. Build and upload to M5StickC Plus2
