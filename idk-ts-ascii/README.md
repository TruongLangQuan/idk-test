# idk-ts-ascii

Screensaver ASCII cho `Tenstar TS-ESP32-S3`, lấy cảm hứng từ:

- `bash-screensavers`
- `terminal-toys`

Mapping:

- `microSD`: `CS=13`, `MOSI=11`, `CLK=12`, `MISO=10`
- `5-way`: `UP=14`, `DOWN=17`, `LEFT=16`, `RIGHT=18`, `CENTER=15`

Điều khiển:

- `UP/DOWN`: đổi mode
- `LEFT/RIGHT`: giảm hoặc tăng nhịp animation
- `CENTER`: reset pattern

Mode hiện có:

- `Matrix`
- `Tunnel`
- `Rain`
- `Noise`
