# MorphTris v1.1 - L & J Tetrominoes Added!

## 🆕 **What's New in v1.1:**

### **Two New Classic Tetrominoes:**
- **L-Tetromino** (orange) - The classic L-shaped piece
- **J-Tetromino** (blue) - The reverse L-shaped piece

### **Updated Stats:**
- **Total Pieces**: 13 (was 11)
- **Triominoes**: 8 pieces (1-3 blocks each)
- **Tetrominoes**: 5 pieces (4 blocks each)

## 🔄 **Perfect Clockwise Rotation:**

### **L-Tetromino Rotations:**
```
R0:  #     R90: ###    R180: ##     R270:   #
     #          #            #           ###
     ##                      #
```

### **J-Tetromino Rotations:**  
```
R0:   #    R90: #      R180: ##     R270: ###
      #        ###           #             #
     ##                      #
```

Both pieces rotate **clockwise** (to the right) maintaining perfect 4-block tetromino shapes with no morphing!
