🆕 WHAT IS MORPHTRIS?

MorphTris is the ultimate evolution of Tetris gameplay, combining 
pieces from ThreeTris, Quintris, Tetris, and CrossTris into one 
ultra-challenging experience!

Unlike regular Tetris with only 4-block pieces, MorphTris features:
• 1-block pieces (monominos)
• 2-block pieces (dominoes) 
• 3-block pieces (triominoes)
• 4-block pieces (tetrominoes)

Players must constantly adapt their strategy as tiny single blocks 
mix with massive tetrominos in unpredictable combinations!

🔧 PERFECT MECHANICS:

✅ FLAWLESS CLOCKWISE ROTATION
   • All pieces rotate clockwise (to the right)
   • Consistent rotation direction across all piece types
   • No morphing - pieces maintain their shape!

✅ ADVANCED WALL KICK SYSTEM  
   • 6-step wall kick algorithm from ThreeTris v3.3
   • Works on both left and right walls
   • T-spins and tight rotations fully supported
   • NO MORE STUCK PIECES!

✅ MODERN TETRIS FEATURES
   • Ghost piece preview (adapts to piece size)
   • Hold piece system
   • Next piece preview  
   • Progressive difficulty scaling
   • Lock delay system prevents accidental drops

✅ DYNAMIC BLOCK COUNTING
   • Smart system handles 1-4 block pieces seamlessly
   • Each piece uses exactly the blocks it needs
   • No wasted memory or processing

🕹️ CONTROLS:

Mini JoyC Hat:
• Left/Right - Move piece horizontally
• Down - Soft drop (faster fall)
• Up - Hard drop (instant placement)  
• Button - Rotate clockwise

M5StickC Plus2:
• Button A - Hold/swap piece
• Button B - Reset game

📥 INSTALLATION:

Method 1 - ESPTool (Command Line):
esptool.py --chip esp32 --port /dev/ttyUSB0 \
  write_flash 0x10000 MorphTris-v1.0-11pieces-20241201.bin

Method 2 - M5Burner (Recommended):
1. Download M5Burner from M5Stack
2. Load MorphTris-v1.0-11pieces-MERGED-20241201.bin
3. Select your COM port
4. Click "Burn" 
5. Game ready to play!
