🚀 METHOD 1: GITHUB WEB INTERFACE
───────────────────────────────────────────────────────────────────────────

Step 1: Create Repository
  1. Go to https://github.com/new
  2. Repository name: M5StickSonic (or your choice)
  3. Description: "Sonic The Hedgehog for M5StickC Plus2 with DOWN-TO-ROLL"
  4. Set to Public
  5. DO NOT initialize with README (we have one)
  6. Click "Create repository"

Step 2: Upload via Web
  1. Click "uploading an existing file"
  2. Drag the ENTIRE github-release folder contents
  3. OR click "choose your files" and select all
  4. Commit message: "Initial release v1.2.0 with DOWN-TO-ROLL"
  5. Click "Commit changes"

Step 3: Create Release
  1. Click "Releases" on right sidebar
  2. Click "Create a new release"
  3. Tag: v1.2.0
  4. Title: "M5StickSonic v1.2.0 - DOWN-TO-ROLL Edition"
  5. Description: Copy from releases/RELEASE_NOTES.txt
  6. Attach binaries from releases/ folder:
     - M5StickSonic-v1.2-FINAL-MERGED.bin
     - M5StickSonic-v1.2-FINAL.bin
     - bootloader.bin
     - partitions.bin
  7. Click "Publish release"

🖥️ METHOD 2: COMMAND LINE (GIT)
───────────────────────────────────────────────────────────────────────────

Step 1: Initialize Repository
  cd github-release
  git init
  git add .
  git commit -m "Initial release v1.2.0 with DOWN-TO-ROLL mechanic"

Step 2: Create GitHub Repository
  (Do this on GitHub.com first - see Method 1, Step 1)

Step 3: Push to GitHub
  git remote add origin https://github.com/YOUR_USERNAME/M5StickSonic.git
  git branch -M main
  git push -u origin main

Step 4: Create Release via Git
  git tag -a v1.2.0 -m "v1.2.0 - DOWN-TO-ROLL Edition"
  git push origin v1.2.0

Then upload binaries via GitHub web interface (Releases section).

Title: M5StickSonic v1.2.0 - DOWN-TO-ROLL Edition

Description:
───────────
🦔 **Sonic The Hedgehog for M5StickC Plus2 - FINAL RELEASE**

Play the complete Green Hill Zone Act 1 on your M5StickC Plus2!

## 🆕 What's New in v1.2.0

**DOWN-TO-ROLL mechanic** - The feature that makes it feel authentic!
- Press DOWN on joystick while moving → Roll into ball
- Release DOWN → Stand back up
- Just like the original Sonic game!

## 🎮 Features

- Complete Green Hill Zone Act 1
- Authentic Sonic physics
- 211x119 optimized display (88% screen coverage)
- 27-30 FPS smooth gameplay
- Mini Joy C Hat analog joystick
- All classic moves: run, jump, roll, spindash
- Ring collection & enemy AI

## 📦 Installation

**Quick Start (M5Burner):**
1. Download M5StickSonic-v1.2-FINAL-MERGED.bin
2. Flash with M5Burner
3. Connect Mini Joy C Hat
4. Play!

See README.md for full documentation.
